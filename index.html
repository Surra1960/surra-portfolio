StudentHub

A full-stack platform for Addis Ababa University students to access announcements, events, academic resources, practice questions, and student-focused services through structured academic navigation.

  • PostgreSQL academic model covering streams, programs, years, semesters, courses, and resources
  • React frontend with loading, error, empty-state, search, and API integration states
  • JWT authentication, student profiles, and role-based access
Built as a real campus platform rather than a tutorial project, with the architecture designed to support future contributors and more student services.
